# lwcaracerematcmnn (Car Race Arena)

MakeCode Arcade top-down racer by Ezhan.

Open https://arcade.makecode.com > **Import** > **Import URL** or import this folder / the `.mkcd` assets file.

## Controls
- **A** gas · **B** brake/reverse · **Left/Right** steer
- **Up** fire missile · **Down** horn · **Menu** shop

## Features
- 3 tracks (Oval, Figure-8, City) — win a race or buy Next track
- Shop with stackable unlockables: paint, stripes, spoiler, neon, turbo stacks, trail stacks, horn stacks, missiles
- Infinite-coins friendly shop (auto top-up if short)
- Missiles, boost/shield/ammo power-ups, smarter rubber-band rivals
- Engine tone, horns, lap/coin/crash SFX, NeoPixel panel + megablocks assets

## Files
`tracks.ts` `sounds.ts` `car.ts` `rivals.ts` `shop.ts` `powerups.ts` `hud.ts` `main.ts` plus `images.g.ts` / `images.g.jres`.
