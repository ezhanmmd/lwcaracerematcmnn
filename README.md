# Car Race Arena (MakeCode Arcade)

Open https://arcade.makecode.com > **Import** > **Import URL** > paste
`https://github.com/ezhanmmd/car-race-arena`

Controls: A = gas, B = brake/reverse, Left/Right = steer, Menu = shop.
Extensions: light (NeoPixel), net + esp32 (WiFi, hardware only), radio (closest thing to Bluetooth - Arcade has no Bluetooth extension). WiFi name/password are placeholders - never commit real ones.
