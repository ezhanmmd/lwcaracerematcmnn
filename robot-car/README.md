# Robot car receiver

This micro:bit program listens to Ezhan's race game and drives a Kitronik Servo:Lite car.

Radio group: **7** (same as the game).

## Flash it

1. Open https://makecode.microbit.org
2. Click **Import**, then **Import URL**
3. Paste:

   `https://github.com/ezhanmmd/lwcaracerematcmnn/robot-car#robot-remote`

4. Click **Download** and copy the file onto the micro:bit that is plugged into the car.

The LEDs show an arrow for the command (up, down, left, right, or a corner when gas and steering are held together). A small square means stop.

If the game goes quiet for about 1 second, the car stops by itself.
